MakeCode Setup Snippet

Flash this program onto your micro:bit using Microsoft MakeCode (makecode.microbit.org): 

bluetooth.startUartService()

input.onButtonPressed(Button.A, function () {
    bluetooth.uartWriteString("A_PRESSED\n")
    basic.showIcon(IconNames.Yes)
})

input.onButtonPressed(Button.B, function () {
    bluetooth.uartWriteString("B_PRESSED\n")
    basic.showIcon(IconNames.No)
})

input.onGesture(Gesture.Shake, function () {
    bluetooth.uartWriteString("SHAKE\n")
    basic.showIcon(IconNames.Surprised)
})

In MakeCode Project Settings, ensure "No Password Pairing: Anyone can connect via Bluetooth" is selected if you want instant Web Bluetooth pairing without PIN prompts.
