GATT Error Diagnostic Helper

Chrome connected to your micro:bit, but the micro:bit refused to expose the Nordic UART Service (6e400001). Check these mandatory steps:

1. MakeCode Pairing Settings

In MakeCode, click Project Settings ⚙️ and choose "No Password Pairing: Anyone can connect via Bluetooth". Then re-download the .hex file.

2. micro:bit V1 Memory Limits

If using a micro:bit V1, running complex ML blocks alongside Bluetooth causes a memory crash (Error 504). Flash a clean, minimal Bluetooth script first.

MakeCode Reference Program

Paste this code into makecode.microbit.org: 

bluetooth.startUartService()

bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Yes)
})

bluetooth.onBluetoothDisconnected(function () {
    basic.showIcon(IconNames.No)
})

input.onButtonPressed(Button.A, function () {
    bluetooth.uartWriteString("A_PRESSED\n")
})

input.onButtonPressed(Button.B, function () {
    bluetooth.uartWriteString("B_PRESSED\n")
})

input.onGesture(Gesture.Shake, function () {
    bluetooth.uartWriteString("SHAKE\n")
})
