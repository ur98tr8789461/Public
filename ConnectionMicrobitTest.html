MakeCode Setup Snippet

Flash this minimal UART program to your micro:bit in makecode.microbit.org: 

bluetooth.startUartService()
bluetooth.setTransmitPower(7)

bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Yes)
})

input.onButtonPressed(Button.A, function () {
    bluetooth.uartWriteString("A_PRESSED\n")
})

input.onButtonPressed(Button.B, function () {
    bluetooth.uartWriteString("B_PRESSED\n")
})

input.onGesture(Gesture.Shake, function () {
    bluetooth.uartWriteString("SHAKE\n")
})

In MakeCode Project Settings ⚙️, select "No Password Pairing: Anyone can connect via Bluetooth" to bypass Web Bluetooth security blocks.
